# クイックスタート（遊ぶ人向け）

このランチャーを使うと、サーバーと同じsimutrans本体とpaksetを自動でそろえて、サーバーに接続できます。simutransを自分で入れておく必要はありません。

## 用意するもの

始める前に、サーバー管理者から次の2つを教えてもらってください。

| もらうもの | 例 |
|---|---|
| サーバーリストのアドレス | `https://example.ddns.net:8443/manifest.json` |
| 確認コード | `A1B2-C3D4-E5F6-0718-293A` |

確認コードは、サーバーリストが本当に管理者のものかを確かめるための文字列です。ランチャーの画面には表示されないので、必ず管理者から聞いてください。

## 初めて遊ぶまでの手順

1. `Simutrans_Launcher.exe`を好きな場所に置いて、ダブルクリックする
2. 「設定」を押し、プレイヤー名を入れて保存する
3. 「追加」を押し、「サーバー管理者から共有されたリストを追加」を選ぶ
4. 配信アドレスの欄にアドレスを貼り付け、「確認して保存」を押す
5. 確認コードの欄に、管理者から聞いたコードを入れて「確認して登録」を押す
6. 一覧に出たサーバーを選び、「同期」を押す
7. インストール設定の画面が出たら、ダウンロード先を決めて「保存」を押す
8. 同期が終わったら「起動」を押す
9. 「simutrans本体の実行の確認」が出たら、配布元を確かめて「承認して起動」を押す

1の手順で「WindowsによってPCが保護されました」と出たときは、「詳細情報」を押してから「実行」を押してください。ランチャーに電子署名がないため、Windowsが念のため止めています。

7の手順のダウンロード先は、`C:\Games\simutrans`のようにCドライブの直下に作ったフォルダをおすすめします。「ドキュメント」や「デスクトップ」はOneDriveに同期されていることが多く、ダウンロードが止まる原因になります。ダウンロード量は、本体とpaksetを合わせて数百MBです。

9の確認は、同じ本体なら最初の1回だけ出ます。本体が更新されたときは、改めて確認を求めます。

## 2回目から

ランチャーを開いてサーバーを選び、「起動」を押すだけで遊べます。サーバー側で更新があったときは、札が「要同期」や「更新あり」になるので、「同期」を押してから「起動」を押してください。

更新があるかを確かめたいときは「アップデートチェック」を押します。このときダウンロードはしません。

## 接続が切れたとき

simutransの「ゲームに参加」の画面では、アドレスの欄が空になっていることがあります。そのときはランチャーの一覧でサーバーの「コピー」を押し、simutransのアドレスの欄を選んでCtrl+Vで貼り付けてください。ランチャーの「起動」から、simutransを起動し直してもかまいません。

一覧の接続先はふだん「接続先は非表示」と出ています。配信や画面共有で見えないようにするためです。見たいときは「表示」を押してください。「コピー」は表示しなくても使えます。
