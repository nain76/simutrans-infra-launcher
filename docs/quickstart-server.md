# クイックスタート（サーバー管理者向け）

simutransサーバーを動かしているWindows Serverに、友人のランチャーがpaksetと本体を取りに来るための配信サーバーを用意します。作業のほとんどは、`server-setup`フォルダのバッチファイルをダブルクリックするだけで済みます。細かい仕組みは[サーバー側でやること](../server-setup/README.md)にあります。

## 前提

simutransサーバーが、Windows Server上で動いていることを前提にします。友人が接続に使うドメイン（例は`example.ddns.net`）も用意しておいてください。Windows Server 2019以降で動きます。

## 初めての構築

1. `server-setup`フォルダを、Windows Serverの好きな場所（例はデスクトップ）にコピーする
2. `Setup-Server.bat`をダブルクリックし（サーバー管理ツールの「新規構築を始める」でもよい）、「このアプリがデバイスに変更を加えることを許可しますか？」で「はい」を押す
3. サーバー名、ドメイン、simutransサーバーのポート、paksetフォルダのフルパスを聞かれるので答える
4. simutrans本体のexeが複数あれば番号で選ぶ（動いているサーバーのexeが分かれば自動で選ぶ）
5. 署名の鍵が作られ、確認コードが黄色で表示されるので、書き留めておく
6. 「バックアップを作りますか？」にYと答え、パスワードを決める
7. 「HTTPSにしますか？」にYと答え、英語で「Enter email(s)」と聞かれたら自分のメールアドレスを入れる
8. 最後に表示される「残りの作業」を行う

paksetフォルダのフルパスは、エクスプローラーでフォルダをShiftを押しながら右クリックし、「パスのコピー」を選ぶと貼り付けられます。

6の手順でできた`signing-key-backup.json`は、自分のPCやUSBメモリなど、VPSの外に移して保管してください。VPSを作り直したときに、同じ確認コードを使い続けるために必要です。

7の手順でHTTPSにするには、TCP 80番に外から届く必要があります。VPSの管理画面にパケットフィルター（ConoHaなら「セキュリティグループ」）があれば、先にTCP 80と8443とsimutransサーバーのポートを許可しておいてください。

7の手順のメールアドレスは、証明書を出しているLet's Encryptが、証明書に問題があったときなどに連絡する宛先です。証明書には書かれず、友人には見えません。利用規約への同意はスクリプトが済ませるので、聞かれません。

## 友人に伝えること

友人には、DiscordのDMなどで次の2つを伝えます。

| 伝えるもの | 例 |
|---|---|
| サーバーリストのアドレス | `https://example.ddns.net:8443/list-7k3qf9x2m4.json` |
| 確認コード | `A1B2-C3D4-E5F6-0718-293A` |

確認コードは秘密ではないので、見られても問題ありません。ただし、配信サーバーの中に置いて伝えるのはやめてください。友人向けの手順は[クイックスタート（遊ぶ人向け）](quickstart-client.md)にあるので、ランチャーと一緒に渡すと便利です。

## サーバー管理ツール

`Simutrans_ServerManager.exe`を`server-setup`フォルダに置いてダブルクリックすると、サーバー管理の画面が開きます。公開アドレスと確認コードの確認やコピー、お知らせとメンテナンス中の表示の書き換え、各バッチファイルの呼び出しを1つの画面で行えます。書き換えはこれまでのスクリプトが行うので、バッチファイルを直接使ってもかまいません。

## ふだんの作業

アドオンを足したり外したりしたら、simutransサーバーを再起動してから`Publish-Pakset.bat`をダブルクリックします。simutrans本体を入れ替えたときも同じです。友人のランチャーは、次に同期するときに変わったファイルだけを落とします。

simutransサーバーを増やすときは`Add-Server.bat`をダブルクリックします。お知らせを変えたいときは、`Simutrans_ServerManager.exe`（サーバー管理ツール）を開き、お知らせを書き換えて「保存して署名」を押してください。
